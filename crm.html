Tres pasos, una sola vez:
1. Entrá a supabase.com y creá un proyecto nuevo (gratis).
2. Menú SQL Editor → New query, pegá todo el archivo socios/supabase.sql y dale Run. Cambiá la clave de la última línea por una tuya, larga.
3. De Settings → API copiá la Project URL y la llave anon public, pegalas acá abajo con tu clave, y tocá Probar conexión.
